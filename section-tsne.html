Before the Math

Two Analogies

t-SNE is fundamentally different from PCA. Understand the philosophy before the formulas.

🏘️

Rearranging a Neighbourhood

Imagine you have a map of a city with many neighbourhoods. You need to recreate this map on a smaller piece of paper — but the only rule is: keep neighbours together. You don't care about exact distances across the whole city. You push each neighbourhood into a cluster, keep friends close, and don't worry if two distant neighbourhoods end up far apart in different ways than before.

🧲

Magnets and Springs

Imagine each data point is a ball. Points that are similar in high dimensions are connected by a strong spring — they attract. Points that are dissimilar are pushed apart. t-SNE places all the balls randomly, then lets physics run: springs pull similar points together, repulsion pushes everything else apart. The final resting position is the t-SNE layout.

Key difference from PCA: PCA finds a fixed mathematical direction and projects everything onto it. t-SNE has no fixed formula for output — it learns the 2D layout iteratively, optimising for local neighbourhood preservation.
The Algorithm

Five Steps of t-SNE

Each step derives its formula from scratch — where it comes from, why it's written that way, and what problem it solves.

1
Compute High-Dimensional Similarities
For every pair of points in the original high-dimensional space, we ask: how similar are they? We don't use raw distances — instead we convert distances to probabilities using a bell-curve (Gaussian). Close points get high probability; far points get near-zero. The width of the bell-curve (σᵢ) is tuned separately for each point based on the perplexity parameter.
pj|i = exp(−‖xᵢ−xⱼ‖² / 2σᵢ²)
─────────────────────────
Σₖ≠ᵢ exp(−‖xᵢ−xₖ‖² / 2σᵢ²)
Where does this come from?

We start with the Euclidean distance between xᵢ and xⱼ:
dist² = ‖xᵢ − xⱼ‖² — squared distance in high-D space
We pass this through a Gaussian kernel — a bell-shaped function that converts distances to similarity scores:
raw similarity = exp(−dist² / 2σᵢ²)
The denominator normalises over all other points so the values sum to 1 (a valid probability distribution):
p_{j|i} is the probability that xᵢ would choose xⱼ as a neighbour
What is σᵢ?
The bandwidth σᵢ is chosen per-point so that the distribution's entropy matches the chosen perplexity:
Perp = 2^H where H = −Σⱼ p_{j|i} log₂ p_{j|i}
Perplexity ≈ effective number of neighbours considered. Found by binary search on σᵢ.
💡 Perplexity (5–50) controls how many neighbours each point cares about
2
Symmetrise the Probabilities
The conditional probability p_{j|i} is not the same as p_{i|j} — the Gaussian widths σᵢ differ per point. Before we can use these probabilities, we symmetrise them into a single joint probability p_{ij} that represents the probability of the pair (i, j) being neighbours.
pij = (pj|i + pi|j) / 2n
Where does this come from?

The asymmetric conditionals p_{j|i} and p_{i|j} differ because each point uses its own σ. We want a symmetric joint probability P over all pairs (i,j) such that:
p_{ij} = p_{ji} (symmetry is required for the gradient)
Σᵢ Σⱼ p_{ij} = 1 (valid joint probability over all n² pairs)
The simplest symmetric combination that satisfies both is:
p_{ij} = (p_{j|i} + p_{i|j}) / 2n
Dividing by 2n ensures the values sum to 1 over all n² pairs, and symmetry is guaranteed by averaging.

Why does this matter? With symmetric P, every pair (i,j) contributes equally to the cost function. Without symmetry, outlier points with very large σᵢ would dominate.
💡 Symmetrising ensures every pair contributes equally to the layout
3
Define Low-Dimensional Similarities
In the 2D (or 3D) output space, we define a different similarity measure between points yᵢ and yⱼ. We use a Student t-distribution with 1 degree of freedom (also called a Cauchy distribution) instead of a Gaussian. This is the key trick that gives t-SNE its name — and it's what makes the algorithm work much better than its predecessor SNE.
qij = (1 + ‖yᵢ−yⱼ‖²)⁻¹
──────────────────────────
Σₖ≠ₗ (1 + ‖yₖ−yₗ‖²)⁻¹
Where does this come from?

Original SNE used a Gaussian in the low-dimensional space too. The problem: in high dimensions, distances between points are much larger. If we use a Gaussian in low-D too, moderate distances in high-D get mapped to near-zero probability — everything collapses together.

The Student t-distribution with 1 degree of freedom has much heavier tails:
Gaussian tail: falls off as exp(−r²) — drops to zero rapidly
Student-t tail: falls off as (1+r²)⁻¹ — drops much more slowly
This means moderately dissimilar points in high-D can be placed far apart in 2D without losing too much probability — giving clusters room to breathe. The denominator again normalises to sum to 1, making Q a valid probability distribution over all n(n−1) pairs.
💡 The heavy t-distribution tail prevents cluster collapse — the key insight of t-SNE
4
Define the Cost Function (KL Divergence)
Now we have two probability distributions: P (high-dimensional similarities, fixed) and Q (low-dimensional similarities, which change as we move points around). We want Q to match P as closely as possible. The measure of mismatch between two probability distributions is KL Divergence — our cost function to minimise.
C = KL(P ‖ Q) = Σᵢ Σⱼ pij log(pij / qij)
Where does this come from?

KL divergence (Kullback-Leibler divergence) is the standard information-theoretic measure of how different two distributions P and Q are:
KL(P‖Q) = Σᵢ P(i) · log(P(i)/Q(i))
Properties that make it ideal here:
KL(P‖Q) ≥ 0 always (non-negative)
KL(P‖Q) = 0 only when P = Q perfectly
Penalises putting q_{ij} small when p_{ij} is large (nearby points pushed far apart) much more than the reverse
What does this asymmetry mean?
KL is asymmetric: it strongly penalises placing two similar high-D points far apart in 2D. This means t-SNE prioritises preserving local structure (nearby neighbours) over preserving global structure (relative positions of distant clusters).
💡 t-SNE cares much more about keeping close things close than about distant things
5
Minimise via Gradient Descent
We minimise the KL divergence cost by iteratively moving every 2D point yᵢ in the direction that reduces the cost most. This direction is the gradient of C with respect to yᵢ. We apply it using gradient descent — a small step in the downhill direction at each iteration — until the layout stabilises.
∂C/∂yᵢ = 4 Σⱼ (pij − qij)(yᵢ − yⱼ)(1 + ‖yᵢ−yⱼ‖²)⁻¹
Where does this come from?

We differentiate C = Σᵢⱼ p_{ij} log(p_{ij}/q_{ij}) with respect to yᵢ. Since p_{ij} is fixed (high-D data doesn't change), only q_{ij} depends on yᵢ.
Step 1: ∂C/∂yᵢ = −Σⱼ p_{ij} · (1/q_{ij}) · ∂q_{ij}/∂yᵢ
Step 2: Applying chain rule to the Student-t formula: ∂q_{ij}/∂yᵢ introduces the factor (1+‖yᵢ−yⱼ‖²)⁻¹ · (yᵢ−yⱼ)
Step 3: After simplification and symmetrisation, the factor 4 emerges from counting both (i,j) and (j,i) pairs
Reading the gradient:
When p_{ij} > q_{ij}: points are too far apart in 2D → attractive force pulling yᵢ toward yⱼ
When p_{ij} < q_{ij}: points are too close in 2D → repulsive force pushing yᵢ away from yⱼ
Update rule with momentum: Y(t) = Y(t−1) + η · ∂C/∂Y + α(t)·[Y(t−1)−Y(t−2)]
💡 Each iteration is a tug-of-war between attraction (near pairs) and repulsion (far pairs)
Reference

Key Properties of t-SNE

✓ Strengths

  • Captures non-linear structure PCA cannot see
  • Excellent at separating clusters visually
  • Works well on very high-dimensional data (images, text embeddings)
  • Local neighbourhood structure is faithfully preserved
  • Perplexity gives intuitive control over scale of structure

✗ Limitations

  • Does NOT preserve global distances (cluster sizes/positions misleading)
  • Slow — O(n²) per iteration, runs for 1000+ iterations
  • Non-deterministic: different runs give different layouts
  • No inverse transform — cannot project new points
  • Hyperparameter-sensitive: perplexity, iterations, learning rate all matter

⏰ When to Use t-SNE

  • Visualising clusters in high-dimensional data (images, genomics)
  • Exploratory data analysis — finding unexpected groupings
  • When PCA gives a boring flat projection with no separation
  • Inspecting neural network embeddings or word vectors
  • Never for reconstruction or downstream ML (non-invertible)

🌍 Real-World Uses

  • Single-cell RNA sequencing (UMAP now dominant, but t-SNE pioneered it)
  • Visualising word embeddings (Word2Vec, GloVe)
  • Image manifold exploration (MNIST digit clusters)
  • Anomaly detection in high-D sensor data
  • Understanding what neural nets have learned

⚖️ t-SNE vs PCA — When to Use Which

Use PCA when: Linear structure, fast preprocessing needed, you need interpretable components, you want to project new data points, global distances matter, or you need reconstruction.
Use t-SNE when: Non-linear clusters, exploratory visualisation, local group structure matters most, you have time to run it, and you only care about the 2D/3D visual output.
