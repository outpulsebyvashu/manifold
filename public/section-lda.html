The Core Idea

Two Analogies

LDA has a fundamentally different goal from PCA. Understand why labels change everything.

⚖

The Sorting Machine

Imagine you need to sort apples from oranges by rolling them down a ramp. You want to tilt the ramp so apples end up at one end and oranges at the other — as separated as possible. PCA would tilt the ramp to maximise how spread out all the fruit is. LDA tilts the ramp to maximise the gap between apples and oranges, even if the total spread is smaller.

🔎

The Security Scanner

A metal detector at an airport doesn't try to capture every variation in what people carry. It specifically looks for the signal that best distinguishes dangerous from safe items. LDA is the mathematical equivalent: given that you already know which group each point belongs to, find the projection that makes those groups as distinguishable as possible.

The fundamental difference from PCA: PCA is unsupervised — it ignores class labels and finds directions of maximum variance. LDA is supervised — it uses class labels to find directions that maximise separation between classes while minimising spread within each class. LDA can only find at most (C−1) discriminant directions, where C is the number of classes.
The Algorithm

Five Steps of LDA

Each step shows where its formula comes from and what problem it solves.

1
Compute Class Means and Overall Mean
Start by computing the mean of each class separately, and the overall mean of all data. These are the "centres of gravity" that LDA uses to define both where classes are located and where the overall data lives. Every subsequent step references these means.
mu_c = (1/n_c) * sum_{x in class c} x
mu = (1/n) * sum_i x_i
Where does this come from?

The class mean mu_c is simply the centroid of all points belonging to class c. It represents the "typical" location of that class in feature space.

The overall mean mu is the centroid of the entire dataset.

Why do we need both?
We need mu_c to measure how spread out points are within each class (Step 2)
We need mu_c and mu together to measure how far apart the classes are from each other (Step 3)
The gap between mu_c values measures inter-class separation — LDA maximises this
💡 LDA requires knowing which class each point belongs to — unlike PCA
2
Within-Class Scatter Matrix S_W
S_W measures how much the points within each class vary around their own class mean. We want this to be small — tight, compact classes. If all points in a class are clustered tightly around their class mean, LDA can find a good separator.
S_W = sum_c sum_{x in c} (x - mu_c)(x - mu_c)^T
Where does this come from?

The within-class scatter is the sum of covariance matrices of each class:
For each class c, compute: sum_{x in c} (x - mu_c)(x - mu_c)^T
This is exactly n_c * Cov(class c) — the unnormalised covariance
Summing over all classes gives S_W — total within-class spread
Why the outer product (x - mu_c)(x - mu_c)^T?
For a single point, this d×d matrix captures the squared deviation in every feature and every cross-feature direction. Summing all these matrices gives the total scatter across all features simultaneously. It's the multivariate generalisation of variance.

Ideal S_W: small diagonal entries (tight clusters in every feature direction) and small off-diagonal entries.
💡 Small S_W means compact classes — easy to separate
3
Between-Class Scatter Matrix S_B
S_B measures how far apart the class means are from each other. We want this to be large — well-separated class centres. LDA's core optimisation is to find a projection direction that maximises S_B while minimising S_W at the same time.
S_B = sum_c n_c * (mu_c - mu)(mu_c - mu)^T
Where does this come from?

For each class c, the term (mu_c - mu) is the vector from the overall mean to that class's mean — its "offset" from the centre of the whole dataset.
(mu_c - mu)(mu_c - mu)^T: d×d matrix encoding this offset in all directions
Multiplied by n_c: weighted by class size (larger classes count more)
Summed over all classes: total between-class spread in every direction
The Fisher criterion LDA maximises:
J(w) = (w^T S_B w) / (w^T S_W w)
This ratio is the Rayleigh quotient. It asks: projected onto direction w, what is the ratio of between-class variance to within-class variance? Maximising this gives the best separator.
💡 LDA maximises J(w) = between-class spread / within-class spread
4
Solve the Generalised Eigenvalue Problem
To find the direction w that maximises J(w), we take the derivative and set it to zero. The solution turns out to be the eigenvectors of the matrix S_W¹S_B — a generalised eigenvalue problem. The eigenvectors with the largest eigenvalues are the best discriminant directions.
S_B w = lambda * S_W w

equivalently: S_W^{-1} S_B w = lambda w
Where does this come from?

We want to maximise J(w) = (w^T S_B w) / (w^T S_W w).

Taking the derivative with respect to w and setting to zero (using the quotient rule):
d/dw [J(w)] = 0
2 S_B w (w^T S_W w) - 2 S_W w (w^T S_B w) = 0
Dividing by (w^T S_W w) and letting lambda = J(w):
S_B w = lambda * S_W w — generalised eigenvalue problem
If S_W is invertible, multiply both sides by S_W¹:
S_W^{-1} S_B w = lambda w — standard eigenvalue problem
Maximum number of discriminants: S_B has rank at most C−1 (C class means, one degree of freedom lost to the overall mean), so there are at most C−1 non-zero eigenvalues and at most C−1 discriminant directions.
💡 For C classes LDA gives at most C−1 discriminant axes — e.g. 2 axes for 3 classes
5
Project onto Discriminant Axes
Once we have the top discriminant directions (eigenvectors of S_W¹S_B), we project all data points onto them. The result is a lower-dimensional representation where classes are as well-separated as possible. For C classes you get at most C−1 dimensions, which is often just 1D or 2D.
Z = X W_LDA

W_LDA = [w_1 | w_2 | ... | w_k]
Where does this come from?

Let W_LDA be the d×k matrix of the top k eigenvectors of S_W^{-1} S_B.

For each data point x, the projection is:
z = W_LDA^T x — one row of Z per point
Z = X W_LDA — all n points at once
What the projected coordinates mean:
Each coordinate z_k = w_k^T x is how much x lies along the k-th discriminant axis
LD1 is the single direction that best separates all classes
LD2 (if exists) is perpendicular to LD1 and gives the next-best separation
Classification: after projecting, assign new points to the class whose projected mean is nearest. LDA is the optimal linear classifier under Gaussian class-conditional distributions.
💡 The projected means are as far apart as possible — ideal for classification
Reference

Key Properties of LDA

✓ Strengths

  • Uses class labels — discriminative, not just descriptive
  • Optimal linear classifier (under Gaussian assumptions)
  • Interpretable: each LD axis has feature weights
  • Fast and closed-form (no iterative optimisation)
  • Naturally reduces to C−1 dimensions

✗ Limitations

  • Requires labelled data (supervised only)
  • Assumes Gaussian class distributions
  • Assumes equal class covariances (if not: use QDA)
  • Maximum C−1 output dimensions
  • Linear only — fails on non-linearly separable classes

⌛ When to Use LDA

  • Classification preprocessing — reduce dimensions before a classifier
  • When class separation matters more than variance explained
  • Face recognition (Fisherfaces method)
  • When classes are known and linearly separable
  • Small datasets where non-linear methods overfit

🌎 Real-World Uses

  • Fisherfaces — classic face recognition algorithm
  • Medical diagnosis (separating disease states)
  • Marketing segmentation with labelled customer groups
  • Signal processing — separating known signal types
  • Chemistry — discriminating compound classes

Goal Maximise total variance explained Maximise class separation
